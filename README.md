# Numerical Experiments for Discretization-Free Exact Recovery in the GHCM

This repository contains the code and data used to generate the phase diagrams in the paper *Discretization-free exact recovery in the geometric hidden community model*.

The numerical experiment studies the discretization-free Greedy propagation rule and, in particular, its behavior in the regime where the exact-recovery condition holds but the witness-connectivity condition used by the block construction does not.

## Model used in the numerical experiment

We consider a three-community geometric hidden community model in dimension $d=2$, with $\pi=\left(\frac12,\frac3{10},\frac15\right)$, $r=3$.

For $p\in[1/2,1)$, the binary observation distribution at distance $y\in[0,r]$ is

$$
P_{ab}(y)=
\begin{cases}
\text{Ber}(p),
& a=b,\quad y\in[0,r/3)\cup(2r/3,r],\\
\text{Ber}(1-p),
& a\neq b,\quad y\in[0,r/3)\cup(2r/3,r],\\
\text{Ber}(1/2),
& y\in[r/3,2r/3].
\end{cases}
$$

For this model, $D_+(p)=\frac13\left(1-2\sqrt{p(1-p)}\right)$, $\ell=r/3$, and $\pi_{\mathrm{wit}}=1/2$.
The empirical figure is therefore displayed in the $(\lambda,D_+)$ plane together with the theoretical boundaries.

## Numerical experiment

For each cell of the adaptive $(\lambda,D_+)$ grid, the notebook:

1. generates independent GHCM realizations.
2. labels the vertices in the centered initial box of half-width $r\sqrt{\log n}$ using the ground truth.
3. runs the discretization-free Greedy propagation rule.
4. applies the refinement step.
5. records whether exact recovery is achieved.

The ground-truth initialization is used to focus the experiment on the propagation step. Exact recovery is measured by $\mathbf 1_{\{\widehat{\sigma}=\sigma^*\}}$. A trial is successful only when every vertex is correctly labeled.

The grid is refined recursively near the exact-recovery boundary. In the current experiment, $n=10\,000$, the maximum refinement depth is $5$, cells along the boundary use $20$ independent trials, and the remaining cells use $10$ trials. These parameters and the random seed are collected at the end of `Figure2_EmpiricalExactRecoveryPhaseDiagram.ipynb`.

## Installation

The code requires Python 3 and the packages listed in `requirements.txt`.

A minimal setup is:

```bash
python -m venv .venv
source .venv/bin/activate          # Linux/macOS
# .venv\Scripts\activate           # Windows

python -m pip install --upgrade pip
pip install -r requirements.txt
jupyter lab
```

Jupyter Notebook can be used instead of JupyterLab.

## Running the experiment  

Open the corresponding notebook and run all cells from top to bottom.

The raw trial-level CSV is saved so that additional statistics can be computed without rerunning the simulations.

The simulations use deterministic random seeds. The raw and aggregated data used for the empirical phase diagram are included in `results/`.
For a clean reproducibility check, restart the kernel and run the notebook from the first cell to the last cell.
